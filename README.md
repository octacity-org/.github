# Octacity Community Files

> 🌐 For the Turkish version of this document, see [README_tr.md](./README_tr.md).

This repository contains the shared community standards, policies, and templates used across the Octacity organization.

## Contents

- [`profile/README.md`](profile/README.md) — Octacity's public organization profile
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — general contribution guidelines
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — community behavior standards
- [`SECURITY.md`](SECURITY.md) — security reporting guidance
- [`SUPPORT.md`](SUPPORT.md) — where to ask questions or request help
- [`GOVERNANCE.md`](GOVERNANCE.md) — organizational structure and decision-making
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) — default issue templates
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — default pull request guidance

These files act as organization-wide defaults where supported. Individual repositories may provide project-specific versions when their requirements differ.
