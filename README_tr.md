# Octacity Topluluk Dosyaları

> 🌐 English version: [README.md](./README.md).

Bu depo, Octacity organizasyonu genelinde kullanılan ortak topluluk standartlarını, politikaları ve şablonları içerir.

## İçerik

- [`profile/README.md`](profile/README.md) — Octacity'nin herkese açık organizasyon profili (İngilizce)
- [`CONTRIBUTING_tr.md`](CONTRIBUTING_tr.md) — genel katkı kuralları
- [`CODE_OF_CONDUCT_tr.md`](CODE_OF_CONDUCT_tr.md) — topluluk davranış standartları
- [`SECURITY_tr.md`](SECURITY_tr.md) — güvenlik bildirimi rehberi
- [`SUPPORT_tr.md`](SUPPORT_tr.md) — soru sormak veya yardım istemek için nereye başvurulacağı
- [`GOVERNANCE_tr.md`](GOVERNANCE_tr.md) — organizasyon yapısı ve karar alma süreci
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) — varsayılan issue şablonları
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — varsayılan pull request rehberi

Bu dosyalar, desteklendiği yerlerde organizasyon genelinde varsayılan olarak geçerlidir. Gereksinimleri farklı olan depolar, projeye özel sürümlerini sağlayabilir.
